# Verse Catcher

Listens to a sermon in the browser, detects Bible verses that are quoted or called out, and shows them on a projector screen.

- Open the site in Chrome or Edge. Speech recognition (Whisper) runs inside the browser; the model downloads once per computer.
- Built-in translations: KJV, BSB, NHEB, AKJV, ASV, YLT (public domain).
- Licensed translations (NIV, NKJV, NLT) load through API.Bible with your own key: **Online Bibles…** in the toolbar. The key is stored only in your browser.
